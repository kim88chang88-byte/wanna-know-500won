# Q&A(자주 묻는 질문) 메모

첫 화면 Q&A 는 `src/components/landing/faq.ts` 에서 고쳐요. 답변에는 **지금 실제로 되는 기능만** 적어요.

## 회원가입이 좋은 이유 (근거 킵 — 필요할 때 Q&A·로그인 안내 문구로 꺼내 써요)
1. **보관**: 로그인 없이 본 풀이는 화면을 닫으면 남지 않아서 보관하기 어려워요. 회원은 본 풀이가 '내 보관함'에 저장되고, 다시 볼 때 추가 비용이 없어요. (구현됨)
2. **어디서든**: 휴대폰·컴퓨터 어디서든 로그인하면 같은 보관함을 볼 수 있어요. (구현됨)
3. **다시 입력 안 해도 돼요**: 동의하면 도리가 생년월일시를 기억해서 다음부터 입력을 건너뛰어요. (구현됨)
4. **내가 지울 수 있어요**: 보관함 항목·기억한 정보를 직접 지울 수 있고, 탈퇴하면 함께 삭제돼요. (구현됨)

> 아직 없는 기능은 적지 않아요. (예: 서버 기준 무료 횟수 관리, 알림 등은 켜진 뒤에 추가)

## 첨부 캡처(사주아이 FAQ)에서 가져온 질문
- "어떤 서비스인가요?" → 우리 서비스 소개로 바꿨어요.
- "무엇을 근거로 만들어지나요?" → 계산(프로그램) + 해석(도리) 구조로 바꿨어요.
- "태어난 시간을 몰라도 볼 수 있나요?" → 시주 비움 + 시간 후보 기능 안내로 바꿨어요.
- 아직 안 만든 것: "무료로 볼 수 있는 건 무엇인가요?", "사주를 보면 미래를 알 수 있나요?" (필요하면 추가)
