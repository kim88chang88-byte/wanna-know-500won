# 결과지 카드 (인스타 스토리용)

뽑기 결과를 양피지 + 밀랍 씰("花") + 꽃거지 말풍선 모양의 **9:16 이미지**로 보여주고, 저장·공유할 수 있어요.

## 구조
| 파일 | 역할 |
|---|---|
| `src/lib/card/drawCard.ts` | 캔버스에 카드를 그리는 함수. 360×640 좌표로 그리고 3배(1080×1920)로 확대해요. 무작위 값을 쓰지 않아 같은 입력이면 같은 그림이 나와요. |
| `src/lib/card/data.ts` | 풀이 → 카드 데이터 변환, 읽기용 설명(aria-label), 파일 이름 |
| `src/lib/card/text.ts` | 한글 줄바꿈, 글자 크기 줄이기, 넘치면 `…` |
| `src/components/landing/ResultCard.tsx` | 화면에 보이는 카드 + "이미지로 저장" / "공유하기" 버튼 |

## 동작
- 화면에 보이는 캔버스가 곧 저장되는 이미지예요. (보이는 것과 저장되는 것이 같음)
- 웹폰트(Noto Serif KR)를 최대 1.5초 기다렸다가 그려요. 못 받으면 기본 글꼴로 그립니다.
- **공유하기**: 휴대폰 등 공유 창을 쓸 수 있으면 PNG 파일을 공유 창으로 넘기고(인스타 앱을 고를 수 있음), 아니면 이미지 저장으로 대신해요. 웹에서 인스타그램 스토리로 바로 올리는 방법은 없어서, 저장 후 직접 올리는 흐름이에요.
- 파일 이름은 `kkotgeoji-capsule-YYYYMMDD.png` (일부 환경에서 한글 이름이 `download` 로 바뀌는 문제가 있어 영문으로 했어요).

## 잠긴 내용
카드에는 **점수만** 들어가요. 연애·금전·마음운의 풀이 문장은 서버가 아예 내려보내지 않으므로(`docs/AI_READING.md`) 카드에도 없고, 그 자리는 자물쇠 + 가림막 모양으로 그려요.

## 긴 문장
꽃거지 한마디는 프롬프트에서 120자 안팎으로 요청해요. 더 길면 글자를 줄이고(최소 10px), 그래도 넘치면 `…` 로 잘려요.

## 고칠 때
- 색·글꼴: `drawCard.ts` 맨 위 `C`, `SERIF`, `SANS`
- 레이아웃을 바꾸면 긴 문장/짧은 문장 둘 다 눈으로 확인하세요.
- 카드를 꽃거지 캐릭터 이미지로 꾸미고 싶다면, 이미지를 `public/` 에 두고 `drawImage` 로 그리면 돼요. (다른 주소의 이미지는 캔버스를 "오염"시켜 저장이 막힐 수 있으니 같은 사이트 안의 파일을 쓰세요)
