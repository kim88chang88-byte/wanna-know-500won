# 포토카드 (SNS 공유)

결과 화면 맨 위에 **인스타 감성 포토카드**가 나오고, 바로 공유할 수 있어요.

## 구성
- `src/lib/premium/topic.ts` — 자판기 주제(연애·결혼/궁합·재물·성공·건강·학업·종합)별 맞춤 분석을 규칙 기반으로 만듦. 같은 입력이면 항상 같은 결과.
- `src/lib/card/photoData.ts` — 카드에 들어갈 값(주제, 헤드라인, 한마디, 해시태그 3개, 행운 컬러/방향, 날짜), 대체 텍스트, 공유 문구, 파일 이름.
- `src/lib/card/drawPhotoCard.ts` — 360×640 좌표로 그리는 캔버스 디자인 (파스텔 오로라 배경 + 살짝 기운 폴라로이드 + 마스킹 테이프 + 해시태그 칩). 이모지는 쓰지 않아 폰트에 따라 깨지지 않아요.
- `src/components/landing/PhotoCard.tsx` — 1080×1920(인스타 스토리 규격)으로 그리고 버튼 3개를 제공.

## 공유 방식
1. **인스타·SNS에 공유하기**: 모바일은 Web Share(파일 포함)로 공유 시트가 열려요. 인스타그램·카카오톡을 거기서 고릅니다.
2. 공유 시트를 쓸 수 없는 환경(대부분의 PC)은 이미지 저장 + 해시태그 복사로 대체해요.
3. **이미지로 저장**, **해시태그 복사**는 항상 따로 쓸 수 있어요.
인스타그램에 웹에서 직접 게시하는 공식 방법은 없어서 위 방식이 한계예요.

## 한마디 문구
`ANTHROPIC_API_KEY`가 있어 AI 한마디가 오면 그 문장을, 없으면 주제별 규칙 기반 문장을 써요.
