# Stitch 요청서: 500원 사주 첫 랜딩 흐름

Stitch의 "wanna-know-500won" 프로젝트에 **새 화면**으로 추가해줘. 기존 화면은 수정하거나 삭제하지 마.
모든 화면은 모바일 세로(390×844) 기준, 한국어 문구 그대로 사용.

## 공통 분위기
- 동네 문방구 뽑기 기계처럼 따뜻하고 장난스러운 느낌. 복주머니, 동전 같은 한국적 소품.
- 배경은 연한 분홍(첨부 상품 카드와 같은 톤), 글자와 포인트는 진한 자두색(버건디 계열).
- 숫자(500원 등)는 굵은 세리프체로, 본문은 둥근 고딕체로.
- 캐릭터 "꽃거지 도사": 머리에 꽃을 꽂은 귀엽고 밝은 표정의 오리지널 캐릭터. 부담스럽거나 초라해 보이지 않게, 장난기 있고 믿음직한 도사 느낌.

## 화면 1. 첫 랜딩 (극도로 단순하게)
보이는 것은 아래 4가지뿐. 소개글, 후기, 푸터는 넣지 마.
1. 맨 위 메뉴탭: 짧은 가로 탭 (홈 / 내 사주 / 이용방법 / 마이)
2. 꽃거지 도사 캐릭터: 자판기 옆에서 기대에 찬 표정
3. 500원 캡슐 자판기: 화면 중앙에 크게. 투명 캡슐이 가득, 500원 동전 표시
4. 하단 큰 버튼: "첫 뽑기 무료"
추가로 자판기 아래에 작은 한 줄만: "500원으로 보는 내 사주"

## 화면 2. 생년월일 입력 (하단에서 올라오는 시트)
"첫 뽑기 무료" 버튼을 누르면 뜨는 화면. 최소한만 받아줘.
- 제목: "도사님이 사주를 살펴볼게요"
- 생년월일 (양력/음력 토글)
- 태어난 시간 (선택, "모르겠어요" 체크 가능)
- 성별
- 버튼: "뽑기 돌리기"
- 아래 작은 글씨: "입력한 정보는 결과를 보여주는 데만 써요"

## 화면 3. 뽑기 연출
자판기 손잡이를 돌리면 캡슐이 떨어지고, 캡슐이 열리며 결과로 넘어가는 장면.
꽃거지 도사가 "어디 보자..." 같은 짧은 말풍선. 글자는 최소한으로.

## 화면 4. 무료 뽑기 결과 (일부 블러 처리)
호기심을 만드는 화면. 보이는 것과 가려진 것을 아래처럼 나눠줘.

**또렷하게 보이는 것**
- 상단: "오늘의 총운" 큰 점수 또는 별 5개 중 몇 개, 한 줄 요약
- 꽃거지 도사의 코멘트 **첫 줄만**

**블러 처리 (흐리게, 그래도 "뭔가 있다"는 게 느껴지게)**
- 4대 지표 중 연애운·금전운·마음운: 각 항목의 이름과 아이콘은 보이고, 점수와 설명 문장은 블러
- 도사의 코멘트 나머지 줄
- 인스타 스토리용 결과 카드 미리보기 (윤곽만 보이게 블러)
- 블러 위에 작은 자물쇠 아이콘

**하단 버튼 두 개**
- 주 버튼: "500원으로 전체 열기"
- 보조 버튼: "다시 돌려보기"
- 맨 아래 작은 글씨: "재미로 보는 오늘의 운세예요"

## 화면 5. 상세 랜딩의 상품 카드 (첨부 이미지 구성 그대로)
결과 화면에서 아래로 스크롤하거나 "자세히 보기"를 눌렀을 때 나오는 상세 랜딩 일부.
- 상단 뱃지: "첫 1회 무료 체험권 포함"
- 제목 "일반 뽑기" (오른쪽에 동전 아이콘)
- 가격: "500원" 크게, 옆에 작게 "/ 1회 즉시"
- 설명: "오늘의 기운이 궁금할 때 출퇴근길 가볍게 뽑아보는 일일 낭만 캡슐입니다."
- 포함 목록 (체크 아이콘)
  - 오늘의 총운 & 연애·금전·마음운 4대 지표
  - 꽃거지 도사의 1:1 감성 속삭임 코멘트
  - 인스타 스토리용 모바일 결과지 카드 제공
- 제외 항목 (X 아이콘, 흐린 색): 연간 대운 및 월별 상세 흐름 분석 제외
- 하단 버튼: "뽑기 시작"

# 구현할 때 필요한 결과 데이터 (참고, Stitch에는 넣지 않아도 됨)
```ts
interface DrawResult {
  total: { score: number; summary: string };          // 공개
  indicators: {
    love:  { score: number; text: string };           // 무료 결과에서는 블러
    money: { score: number; text: string };
    mind:  { score: number; text: string };
  };
  comment: { firstLine: string; rest: string[] };     // firstLine만 공개
  shareCard: { imageUrl: string };                    // 무료 결과에서는 블러
}
```
- 블러는 화면에서만 처리하지 말고, 무료 결과 API 응답에 가려진 항목의 실제 내용을 아예 포함하지 않는 것이 안전해요. (개발자 도구로 블러를 풀어 볼 수 있기 때문)
