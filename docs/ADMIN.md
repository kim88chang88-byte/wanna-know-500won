# 관리자 화면 (/admin)

주소: `https://내도메인/admin` (검색에 노출되지 않도록 noindex 예요. 사이트 메뉴에는 링크가 없어요)

## 켜는 방법 (처음 한 번)
1. 사이트에서 평소처럼 로그인해요. (카카오·구글·네이버 어느 쪽이든 괜찮아요)
2. `/admin` 에 들어가면 "관리자 권한이 없어요" 화면에 **내 고유번호**가 보여요. (본인 것만 보여요)
3. Vercel > Settings > Environment Variables 에 `ADMIN_USER_IDS` 를 만들고 그 번호를 넣어요. 여러 명이면 쉼표로 구분해요. (예: `12345678,g_abc123`)
4. 다시 배포(Redeploy)하면 같은 주소에서 통계가 열려요.

> 환경변수가 비어 있으면 **아무도** 관리자가 아니에요. 번호가 목록에 없으면 데이터는 한 줄도 내려가지 않아요.

## 보이는 것
- 전체 회원 수 / 생년월일시를 기억한 회원 수 / 전체 뽑기 / 고민 통계 동의 건수
- 최근 7·30·90일: 로그인 회원의 날짜별 뽑기, 신규 가입, 주제별 뽑기
- 많이 고른 고민 순위, 나이대별 상위 고민, 성별 분포
- 직접 쓴 고민 글 최신 50건 (화면에는 글을 문자열로만 그려요)
- "고민 통계 CSV 내려받기" (엑셀에서 열 수 있어요. 수식으로 실행되지 않게 처리해요)

회원번호·닉네임·생년월일은 이 화면과 CSV 어디에도 나오지 않아요.

## 사용후기
- 결과 화면 맨 아래에서 별점(필수)과 한 줄 후기(선택)를 받아요. 별점이 3점 이하면 "아쉬웠던 점" 칩(최대 3개)도 물어봐요.
- 관리자 화면의 "사용후기" 칸에서 평균 별점, 후기 수, 별점 분포, 아쉬웠던 점 순위, 최신 후기 50건을 봐요.
- 후기마다 **숨기기 / 다시 보이기** 버튼이 있어요. 숨긴 후기는 평균·분포에서 빠지고 목록에는 흐리게 남아요. (현재는 사이트에 후기를 공개하지 않아서, 숨기기는 통계에서 제외하는 용도예요)
- "후기 CSV 내려받기"로 전체를 엑셀로 받을 수 있어요.
- 로그인하지 않아도 후기를 남길 수 있어요. 로그인한 후기만 회원과 연결되어 탈퇴 때 함께 지워져요.
- 스팸 방지: 한 주소(IP)에서 1시간에 10건까지만 받아요.
- 저장 테이블 `reviews` 는 `supabase/schema.sql` 을 SQL Editor 에서 다시 Run 하면 생겨요. 만들기 전에는 후기 저장이 실패하고 관리자 통계도 오류 안내가 떠요.

## 알아둘 점
- 로그인하지 않은 사람의 뽑기는 서버에 기록되지 않아서 "뽑기" 숫자에 포함되지 않아요.
- 고민 통계는 이용자가 동의한 건만 쌓여요. 동의율이 낮으면 실제 고민 분포와 다를 수 있어요.
- 직접 쓴 글에 개인정보가 적혀 있을 수 있어요. 외부에 공유하지 말고, 필요하면 Supabase 에서 해당 행을 지워 주세요.
- 한 번에 최대 2만 줄(CSV는 5만 줄)까지 읽어요. 데이터가 그보다 커지면 기간을 줄이거나 집계를 SQL 로 옮겨야 해요.
- API: `POST /api/admin/reviews`(숨기기), `GET /api/admin/reviews?days=...`(CSV), `GET /api/admin/stats?days=7|30|90`, `GET /api/admin/concerns?days=7|30|90|all` (둘 다 관리자 세션 필요, 응답은 캐시하지 않아요)
