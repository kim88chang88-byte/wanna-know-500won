# 상상 속 인연(배우자) 이미지 — 기본 규칙

프리미엄 연애·결혼 장에서 "사주로 그려 보는 상상 속 인연" 이미지를 만들 때 **항상** 지키는 규칙이에요.
구현은 `src/lib/ai/image.ts`(`partnerAgeFor`, `spousePrompt`)에 있고, 새 코드·프롬프트를 만들 때도 이 문서를 따라요.

## 1. 연령대 규칙 (이용자 만 나이 기준)

이미지 속 인물은 이용자의 **이성**이고, 연령대는 아래 표로 정해요.

| 이용자 | 만 나이 | 이미지 속 인물 |
| --- | --- | --- |
| 남성 | 20~49세 | 20대 후반 |
| 남성 | 50~59세 | 30대 중반 |
| 남성 | 60세 이상 | 40대 초반 |
| 여성 | 20~29세 | 20대 후반 |
| 여성 | 30~39세 | 30대 중반 |
| 여성 | 40세 이상 | 40대 초반 |

## 2. 미성년자(만 20세 미만)는 이미지를 만들지 않아요

- 10대(만 19세 이하) 이용자에게는 인물 이미지를 **만들지 않고**, 그 자리는 글로만 보여 줘요.
- 이유: 미성년자에게 연애·배우자 상대 인물 이미지를 만들어 주지 않기 위해서예요. 10대 후반 인물도 만들지 않아요.
- 나이를 알 수 없을 때도 만들지 않아요(`partnerAgeFor` 가 `null`).
- 이미지 속 인물은 어떤 경우에도 **분명한 성인**이어야 해요(프롬프트에 연령대와 "clearly an adult"를 넣어요).

## 3. 공통 안전 규칙

- 가상의 인물: 실존 인물·연예인을 닮지 않게 하고, 글자·로고·워터마크는 넣지 않아요.
- 화면에는 "AI가 만든 가상의 인물, 재미로 보는 참고용 상상도" 문구를 꼭 붙여요.
- 오행에 따라 옷 색·분위기만 달라지고, 외모 우열을 말하지 않아요.
- 비용: 한 장당 이미지 출력 토큰으로 어림해요(표본 페이지에서 확인). 프리미엄 한 건당 한 장까지만 만들어요.

## 4. 확인 방법

관리자 로그인 후: `/api/admin/image-sample?user=male&userAge=55&el=water`
(`user`, `userAge` 를 넣으면 위 규칙이 적용돼요. 미성년 나이를 넣으면 이미지 대신 안내 문구가 나와요.)
