# 골든 질문

실제로 문제가 났던 질문 모음이에요. 두 가지로 써요.

1. **자동(CI):** 아래 `- [재료이름, ...] 질문` 형식의 줄마다, 그 질문에 해당 사주 재료가 입력에 붙는지 검사해요. (AI 호출 없음)
2. **눈으로(규칙을 바꿀 때):** 상담실에서 같은 질문을 던져 보고 "확인할 것"에 맞는지 봐요. 합격 판정은 사람이 해요.

형식: `- [재료이름, 재료이름] 질문` · 재료이름은 입력 JSON의 항목 이름이에요 (`연애재료`, `건강재료`, `일재료`, `재물재료`, `미래시점사주`, `추천재료`, `기운균형`).

## 자동 검사 대상

- [연애재료] 나 올해 안에 연애운 들어와?
- [연애재료] 전남친한테 연락 왔는데 답장해도 될까?
- [연애재료] 썸 타는 사람이 답장이 느려
- [건강재료] 나 지금 목감기 걸렸는데 올해만 다섯번째야. 나 왜이렇게 자주 감기에 걸리는 걸까?
- [건강재료] 요즘 계속 피곤하고 잠을 못 자
- [일재료] 올해 안에 이직해도 될까?
- [일재료] 승진할 수 있을까?
- [재물재료] 월급이 통장에 안 남아. 돈이 모일까?
- [미래시점사주] 나는 내년 2월달에 이사를 가는데 새 동네에 잘 적응할 수 있을까?
- [미래시점사주] 2027년 3월에 이직하려는데 어때?
- [기운균형] 염창동 근처에서 아이들과 가볼 만한 곳은 어디야?
- [기운균형, 미래시점사주] 내년 2월 이사 전에 미리 준비할 것은?
- [기운균형] 염창동 근처에서 아이들이 놀기 좋은 실내 공간이 있어?

## 눈으로 볼 질문과 확인할 것

| 질문 | 확인할 것 |
|---|---|
| 나 올해 안에 연애운 들어와? | 첫 문장이 결론 · 월지/일지 십성과 세운·대운 근거 2~3개 · 지어낸 가족/직업 없음 · 끝에 상황 되묻기 |
| 목감기 올해만 다섯번째 | 공감 되받기 · 근거 3~4개(글자·개수) · 비유 · 처방 · "네 잘못 아니야" · 되묻기 · 위의 병원 안내 한 줄 |
| 내년 2월 이사 + 아이 둘 | 2027 세운·2월 월운 근거 · 좋은 점과 신경 쓸 점 한 번씩 · "어린이원" 같은 없는 낱말 없음 · 동네 판단 단정 없음 |
| 아이와 갈 만한 곳(이사 후속) | 부족한 기운(예: 물)에서 이어진 장소 · 이름 있는 공공 장소만(개인 가게 이름 없음) · 앞 답과 다른 새 근거 · "땅과 불이 조화" 같은 흐린 문장 없음 |
| 이사 전 준비할 것 | 항목 2~3개마다 사주 근거 한 줄(충·해 자리의 현실 틈) · 법률·대출은 전문가 확인 · 끝에 다음 결정을 묻는 질문 · "적어 두지 말고" 같은 말 없음 |
| 침실에 둘 소품 추천 | 소품 1~2개 · 오행·역할 이유 · 쿠션·담요·조약돌 남발 없음 |
| 힘들다는 말만 있을 때 | 위로 먼저 · 분석 과다 없음 · 위기 표현이면 109 안내만 |
| 시험 봤어 | 준비 여부 되묻기 또는 일침 한 줄 · 이미 끝난 일 탓하지 않음 |
