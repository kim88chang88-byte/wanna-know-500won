# 도유상담실 기준 문서

도리(도유상담실)가 답하는 방식의 **기준(원본)** 이에요. 프롬프트 규칙은 여기 있는 md가 원본이고, 코드는 이걸 빌드 때 가져다 써요.

## 구조

| 위치 | 역할 |
|---|---|
| `prompt/*.md` | AI에게 그대로 들어가는 규칙. **파일 이름의 숫자 순서대로** 이어 붙어요 |
| `코드-강제-규칙.md` | 프롬프트가 아니라 **코드가 100% 강제**하는 규칙(오타 교정, 금지 제안 삭제, 위기 안내 등) |
| `변경-이력.md` | 언제 어떤 질문에서 무슨 문제가 나서 어떤 규칙을 넣었는지 |
| `골든-질문.md` | 문제가 났던 실제 질문 모음. CI가 "질문 → 어떤 사주 재료가 붙는지"를 매번 검사해요 |

## 수정하는 법

1. `prompt/` 안의 해당 주제 파일(연애·건강·재물 등)을 고쳐요. 새 주제면 번호 붙여 새 파일을 만들어요.
2. `node scripts/build-chat-rules.mjs` 로 `src/lib/ai/chatRules.generated.ts` 를 다시 만들어요. (배포 빌드 때도 자동으로 다시 만들어요. 커밋에도 포함해야 CI가 통과해요.)
3. `변경-이력.md` 에 날짜·계기·바뀐 규칙을 한 줄 적어요.
4. 문제가 났던 질문이면 `골든-질문.md` 에 추가해요.

## 꼭 알아둘 점

- md에 적는다고 AI가 100% 따르지는 않아요. 꼭 지켜야 하는 건 **코드로도 강제**하고, 그 사실을 `코드-강제-규칙.md` 에 적어요.
- `{{PALETTE}}` 처럼 겹중괄호로 쓴 자리는 코드가 실제 목록(색·소품·노래 등)으로 바꿔 넣는 자리예요. 이름을 바꾸거나 새로 만들려면 `chat.ts` 에도 값을 추가해야 해요(없으면 빌드·테스트가 실패해서 바로 알 수 있어요).
- 규칙을 늘리면 호출마다 비용이 늘고 규칙끼리 부딪혀서 오히려 덜 따라요. 비슷한 규칙은 합치고, 효과가 확인된 것만 남겨요.
- 입력 항목 이름(`연애재료`, `건강재료`, `미래시점사주` 등)은 코드(`buildChatPrompt`)가 만드는 이름과 같아야 해요.
