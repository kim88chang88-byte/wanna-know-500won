# 코드로 강제하는 규칙

프롬프트에만 맡기지 않고 `src/lib/ai/` 의 코드가 답을 거르거나 고치는 것들이에요. (함수 이름은 `chat.ts` 기준)

| 규칙 | 담당 코드 | 동작 |
|---|---|---|
| 위기·자해 표현은 AI를 부르지 않고 정해 둔 안내만 | `isCrisis`, `CRISIS_ANSWER`, AI의 `risk` 표시 | 안내 번호는 109만 사용 |
| 입력 항목 이름이 답에 새지 않게 | `stripInternalTerms` | "연애 재료를 보면" → "사주를 보면", "원국" → "타고난 사주" |
| 오행 낱말 통일 | `unifyElementWords` | "금 기운" → "쇠 기운" 등(○ 기운 꼴만) |
| 자주 나오는 오타·신조어 교정 | `fixTypos` | 고맙어→고마워, 어린이원→어린이집 등 |
| 노트·메모 쓰기 제안 금지 | `dropBannedSuggestions`(WRITE_SUGGEST) | 해당 문장 삭제 |
| 알림 끄기·차 한 잔 제안 금지 | `dropBannedSuggestions`(ALARM_OFF, TEA_TIP) | 해당 문장 삭제 |
| 밤에 밖으로·낯선 곳 가 보기 같은 엉뚱한 제안 | `dropBannedSuggestions`(NIGHT_OUT, NEW_PLACE) | 해당 문장 삭제 |
| 식상한 일반 팁(서랍 정리·타이머 등) | `dropBannedSuggestions`(BORING_TIP) | 해당 문장 삭제 |
| 같은 문장 반복 | `dedupeSentences` | 중복 문장 삭제 |
| 질문 끝맺음이 연달아 같지 않게 | `softenAskEnding`, `recentEndings` | 끝 질문을 평서문으로 완화 |
| 이어 묻기 칩 중복·주제 이탈 | `cleanFollowups`, `varyFollowups`, `CAREER_OFFTOPIC_CHIP` | 거르고, 남은 게 없을 때만 원본 유지 |
| 소품 카드는 1~2개, 목록 안의 것만, 질문 장소와 맞게 | `cleanVisual`, `narrowLucky` | 개수 제한·장소 맞춤 |
| 카드(visual)는 질문이 요청할 때만 | `visualAllowed` | 아니면 카드 제거 |
| 몸 증상에는 병원 안내 한 줄 | 프롬프트 + `needsDownNote` | 우울·무기력이 계속되면 안내 보강 |
| 궁합 질문에는 궁합 보기 안내 | `addCompatNote` | 안내 한 줄 보장 |
| 여행 답에 확인 문구·출발지 가정 | `addTravelNotes` | 문구 보장 |
| 질문 속 앞으로의 시점(내년 2월 등) 재료 | `futureFacts` (`route.ts` 에서 호출) | 그 시점 세운·월운·원국 관계를 `미래시점사주` 로 전달 |
| 주제별 사주 재료 | `loveFacts`, `careerFacts`, `moneyFacts`, `healthFacts`, `buildCoreFacts` | 질문 낱말로 골라서 입력에 넣음(`buildChatPrompt`) |

새 규칙이 "꼭 지켜야 하는 것"이면 프롬프트에 쓰는 데서 끝내지 말고 위 표에 코드 담당을 추가해요.
